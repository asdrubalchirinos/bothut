## ¿Qué puedes hacer con él?

Correr un agente que guarda memoria, crea **habilidades** a partir de lo que va resolviendo y puede programar tareas. Vive en tu computadora (app de escritorio en Mac y Windows, o terminal en Linux) y también en Telegram, WhatsApp, Slack, Discord, correo y otros canales.

Si no quieres dejar tu PC encendida, **Hermes Cloud** (en el portal de Nous) te presta una máquina encendida todo el día. Eso se paga aparte.

“Hermes” también es el nombre de unos *modelos* de Nous Research, pensados para quien programa. Esta ficha es del **Hermes Agent**, el asistente.

## ¿Qué resuelve mejor?

- **Un agente que se queda contigo** y va armando rutinas.
- **Quien quiere código abierto** pero también una app de escritorio, no solo terminal.
- **Quien acepta pagar el modelo** (clave propia o Nous Portal).
- **No es lo mejor para:** principiantes, ni para quien busca un producto “de consumidor” con WhatsApp listo (Muse). Documentación en inglés.

## ¿Cómo empezar?

1. Si nunca usaste una terminal, detente y prueba antes ChatGPT, Gemini o Grok Bot.
2. Descarga **Hermes Desktop** para Mac o Windows, o instala por terminal desde [hermes-agent.nousresearch.com](https://hermes-agent.nousresearch.com/).
3. Conecta un proveedor: tu propia clave de API **o** una cuenta de [Nous Portal](https://portal.nousresearch.com/).
4. Habla primero en la app. Cuando funcione, conecta un canal (Telegram suele ser el más simple) y limita quién le escribe.
5. Si lo quieres siempre encendido sin tu laptop, revisa Hermes Cloud y el costo por día *antes* de dejarlo corriendo.

## ¿Qué necesitas?

| Pieza | Precio de referencia (EE. UU.) | Obligatorio |
|---|---|---|
| Hermes Agent (el programa) | US$0, licencia MIT | Sí, si lo corres tú |
| Tu clave de API | La cobra cada proveedor | Una de las dos vías |
| Nous Portal Free | US$0; solo modelos gratis, con límite | Opcional |
| Nous Portal Plus / Super / Ultra | US$20 / US$100 / US$200 al mes, con créditos (US$22 / US$110 / US$220) | Opcional |
| Hermes Cloud Medium | US$0.56 al día encendido; US$0.03 apagado | No |
| Hermes Cloud Large | US$1.09 al día encendido; US$0.03 apagado | No |

Cloud pide un mínimo de créditos (Nous muestra unos US$2) o una suscripción activa. El uso del modelo y de herramientas se cobra aparte de la máquina.

**Cuenta:** no hace falta para el programa. Sí hace falta si usas Nous Portal o Cloud.

**Español:** no comprobamos la interfaz. La documentación está en inglés.

**Disponibilidad:** sin bloqueo por país al instalarlo. Pagos de Nous, en dólares.

## Alternativas y cuándo elegirlas

- **OpenClaw:** si te importa sobre todo hablarle por muchos chats y que nadie sea dueño del proyecto (fundación sin fines de lucro).
- **Grok Bot o Dots:** si prefieres pagar un plan y no instalar nada.
- **Muse:** solo si estás en EE. UU. o Canadá y quieres el camino más simple.
- **ChatGPT o Gemini:** para aprender a pedir las cosas, antes de darle a un agente las llaves de tu máquina.
